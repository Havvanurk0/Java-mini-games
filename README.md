# Java Mini Games Collection 🎮
Bu repository, Java öğrenme sürecimde geliştirdiğim temel mantık oyunlarını içermektedir.

## 🚀 İçerik
1. **Sayı Tahmin Oyunu:** Bilgisayarın tuttuğu sayıyı bulmaya çalıştığınız konsol tabanlı oyun.
2. **Tic Tac Toe:** İki kişilik klasik X-O-X oyunu.
3. **Taş Kağıt Makas:** Klasik el oyunu algoritması.

## 🛠️ Kullanılan Teknolojiler
* Java JDK 17+
* Eclipse IDE
